# 黑猫03 SPH34稀疏时间轴实现报告

> 黑猫03只接入参考SPH34的后置处理链，不包含前置B随机跳秒，也不修改AAC `stts` 时间表。黑猫01和黑猫02保持原样。

## 结果

蝴蝶AB工作区新增 `blackcat03` 通道。它先完整播放主视频A，随后进入长度约为辅助视频B的稀疏时间轴；稀疏区默认每30秒插入随机抽取的0.1秒B画面，其余时间由播放器保持A的最后一帧并保持静音，最后播放B真正的末尾1秒音视频。

```text
完整A → 稀疏区（每30秒随机0.1秒B画面）→ B最后1秒音视频
```

输出公开时长约为 `A时长 + B时长`，输出分辨率沿用蝴蝶AB页面的设置，并复用现有CPU/GPU编码选择。

## 实现路径

```mermaid
flowchart LR
    UI["选择黑猫03"] --> D["butterfly_ab.process_batch分派"]
    D --> B["sph34_sparse.process_batch"]

    P --> F["FFmpeg拼接有效帧和音频"]
    F --> T["setpts/asetpts制造后置时间戳空洞"]
    T --> O["H.264 + AAC MP4"]
```

关键文件：

- `app/pages/butterfly_ab_page.py`：显示黑猫03选项。
- `engine/butterfly_ab.py`：将 `blackcat03` 分派到独立实现。
- `engine/sph34_sparse.py`：构造稀疏时间轴并执行批处理。
- `tests/test_sph34_sparse.py`：真实FFmpeg冒烟测试。

## 已知边界

- A和B当前都需要包含音轨，与参考模块的既有前提一致。
- B必须至少1秒，以便取得固定的末尾1秒。
- 当B不足约31.1秒时，中间不会产生30秒间隔片段，但仍保留后置时间轴和B末尾1秒。
- 部分播放器或上传平台可能重新生成时间戳，从而改变稀疏区的播放表现。
